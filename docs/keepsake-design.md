# Chatfold keepsake design

The existing analysis interface stays familiar. The new object is a printable conversation keepsake: an original title spread and a factual activity spread, not an exported transcript. Analysis and CSV/JSON export remain free.

Palette: paper white #ffffff, postal blue #1d41b7, pale blue #e5edff, violet #6554b4, lilac #ebe7ff, graphite #202633. The report uses Georgia for large personal titles and system sans for figures and tables. The purchase area uses the existing interface typography and a quiet blue sample panel.

Layout: left-aligned title and dedication, offset speech shapes as the single memorable motif, followed by clearly labelled totals and contributor tables. Two variants, Correspondence (blue) and After hours (violet), share the same accessible factual content. A4 page breaks define the two-page print experience; no invented sentiment, relationship scores, or hidden inference.

    Title / dedication           speech shapes
    date range                   large message total
    ----------------------------------------------
    Conversation facts           vocabulary
    contributors                 hour-by-hour rhythm

Review: a faux antique paper/serif treatment would have been a generic keepsake cliché. The chosen white/blue correspondence motif comes from the subject's exchange of messages. Existing dark/green site colours are retained only in application chrome, not propagated into the printable product. No third-party art, remote font requests, or private text in public sample previews.
